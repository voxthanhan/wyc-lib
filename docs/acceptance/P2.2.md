## Sản phẩm và contract

[ADR-0006](../adr/0006-p2-node-typed.md) chốt ba hàm object API P1:
`analyze_batch(request)`, `calculate_indicators(data, config, as_of)` và
`analyze_structure(data, config, as_of)`. `AnalysisState(request)` có result,
identity, update_closed_bar, reset và close. API JSON pilot P2.1 giữ nguyên.
Single-module gọi đúng hàm Rust và trả ModuleResult; batch/state trả AnalysisResult.
Khai báo TypeScript bao phủ input/output, 25 indicator keys, structure/evidence,
state cursor và discriminated NumericValue; có consumer strict cùng ca sai kiểu.

Input là plain record, array đặc hoặc Float64Array cho cột số, có copy trước
native call. Chặn NaN/Infinity, unsafe/fractional integer, undefined/BigInt,
cycle/accessor/toJSON, sparse array và class instance trước JSON serialization.
Không thêm công thức, sửa dữ liệu hay giữ reference caller ở wrapper. Close
vĩnh viễn/idempotent; update/reset lỗi giữ state. Sync Node thread, chưa async.

Không đổi Core, fixtures/golden, schema/engine 0.1.0, config-v1/event-v1/p1-v1,
hoặc native Cargo.lock. TypeScript 5.7.3 dev-only, không dependency runtime mới.
Không publish npm/PyPI, tạo release/tag hoặc tích hợp main.

## Native/CI còn phải chạy

Workflow native đã nhận nhánh work/p2-2-node-adapter trên Windows/Linux Node
22.22.0. Runner kiểm locked/clean, Rust suite, native Clippy/build, cài tarball/wheel
ngoài source, compile TypeScript strict, typed Node tests và JSON smoke hai runtime.
Typed tests đối chiếu object APIs với 14 Rust reference snapshots từ pilot;
bao gồm empty/Unicode/zero-volume, module selection, Float64Array, bad shape,
non-finite/precision/missing/enum/error class, ownership, state append/reset
atomic, independent handles, close/GC. Chưa ghi các tests này là native PASS.

Đã được người dùng cho phép rõ gửi source/tài liệu P2.2 lên repository công khai
https://github.com/voxthanhan/wyc-lib. Chạy hai OS, sửa lỗi nếu có, ghi
run/commit/checksum/log thực tế và cập nhật kết luận nghiệm thu. CI P2.1 cũ
không thay bằng chứng P2.2.
