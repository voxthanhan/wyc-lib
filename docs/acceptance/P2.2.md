## Phạm vi và contract

[ADR-0006](../adr/0006-p2-node-typed.md) chốt ba hàm object API P1:
`analyze_batch(request)`, `calculate_indicators(data, config, as_of)` và
`analyze_structure(data, config, as_of)`. `AnalysisState(request)` có result,
identity, update_closed_bar, reset và close. Giữ tương thích API JSON pilot P2.1.
Single-module gọi đúng hàm Rust và trả ModuleResult; batch/state trả AnalysisResult.
Khai báo TypeScript bao phủ input/output, 25 indicator keys, structure/evidence,
state cursor và discriminated NumericValue; compile consumer strict có ca sai kiểu.

Input là plain record, array đặc hoặc Float64Array cho cột số; copy trước native
call. Chặn NaN/Infinity, unsafe/fractional integer, undefined/BigInt,
cycle/accessor/toJSON, sparse array và class instance trước JSON serialization.
Không thêm công thức, sửa dữ liệu hay giữ reference caller ở wrapper. Close
vĩnh viễn/idempotent; update/reset lỗi giữ state. Sync Node thread, chưa async.

Core, fixtures/golden, schema/engine 0.1.0, config-v1/event-v1/p1-v1 và native
Cargo.lock giữ nguyên. TypeScript 5.7.3 dev-only, không dependency runtime mới.
Người dùng đã cho phép rõ ghi .git local và đưa source lên repository công khai
voxthanhan/wyc-lib để tự động cập nhật. Không publish npm/PyPI, release hoặc tag.
