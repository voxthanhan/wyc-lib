## Tiêu chí và sản phẩm

| Tiêu chí P1.4 | Implementation và bằng chứng |
| --- | --- |
| RSI Wilder | SMA n biến động; required=n+1; hằng=50, tăng=100, giảm=0 |
| MACD | EMA fast/slow seed độc lập; line required=slow; signal seed từ q line hợp lệ, required=slow+signal-1; histogram cùng mask signal |
| DI/DX/ADX | DM nghiêm ngặt, tie=0; TR bắt đầu từ chuyển tiếp; DI/DX required=n+1, ADX seed n DX, required=2n; mẫu số 0 cho ready=0 |
| Bollinger | Middle rolling mean; population std; bands middle±k*std, required=n; multiplier hữu hạn >0 |
| Kết quả có thời gian | calculate_advanced trả đúng 11 series, validate toàn snapshot/config rồi chọn AvailableData; metadata/hash và sample timing đúng contract |
| Causal/revision | Mọi prefix của tám fixture so full-input và input cắt tại cùng as_of; future thay bằng 1e120; nến mở/chậm availability; revision không khả dụng bị từ chối |
| Biên/lỗi | Rỗng/một nến/ngắn, n=1/2/3/14/1000000, MACD mặc định và signal=1, âm/zero, tiny/large, missing/non-finite, OHLC/shape, overflow/underflow; input bất biến |
| Ranh giới | indicators → contracts; re-export qua wyc_lib; BasicIndicatorState vẫn chỉ gồm P1.3; state/orchestrator toàn P1 thuộc P1.6 |

Đặc tả contract được bổ sung trước triển khai tại [catalog P1](../algorithms/P1.md).

Tái sử dụng smoothing có offset, range_at, mean/std đã nghiệm thu; thay đổi

## Golden và giới hạn số

Fixture `p1-advanced-v1` gồm tám chuỗi tổng hợp, n=1/2/3/14 và MACD=(1,2,1),
(2,3,2), (1,4,3), (12,26,9). Case mặc định 45 nến dùng công thức modular
nguyên cố định; không randomness, market feed hay credentials.
[Oracle](../../scripts/advanced_oracle.py) tính Fraction exact, smoothing
dạng tổng hình học đóng, RSI=gain/(gain+loss), variance từ khoảng cách cặp
và Decimal sqrt 80 chữ số. Không dùng recurrence Rust làm expected.
[Manifest](../../tests/fixtures/manifest.json) thêm checksum input/golden mới;
golden và checksum các bộ cũ giữ nguyên. Verifier chỉ đọc file hiện có.

Ca large phát hiện triệt tiêu middle-width cỡ 1e100 khiến sai số tương đối
output gần 0 không nằm trong ngân sách thông thường. **Giữ nguyên golden
exact-real**, bổ sung riêng bands của ca này ngân sách tuyệt đối
`8*f64::EPSILON*max(abs(window))` để kiểm sai số làm tròn theo thang input.
Đây là làm rõ giới hạn precision trong catalog, không chỉnh seed, clip số
gần 0 hoặc thay expected bằng output Rust. Các output khác dùng tolerance
cũ; tiny dùng relative-only cho đại lượng giá. Không bảo đảm độ chính xác
tương đối khi output bands gần 0 do triệt tiêu ở thang rất lớn.

Mã: advanced.rs; helpers nội bộ basic.rs; module export và test manifest.

scripts advanced_oracle/verify_oracles/verify_workspace. Tài liệu: README,
ARCHITECTURE, CONTRACTS, API, catalog P1, DEVELOPMENT, fixture README,
CHANGELOG, IMPLEMENTATION_PLAN và báo cáo này. Workflow giữ nguyên matrix,
runner và --locked, verifier buộc đủ năm integration test targets.

RSI/MACD/ADX O(N), Bollinger reference O(N×min(n,N)); output/phụ trợ O(N),
thêm validation O(M) cho toàn snapshot kể cả future. Overflow trung gian
vẫn lỗi dù kết quả lý thuyết hữu hạn; underflow theo f64. P1.4 chưa có mutable
state/serialization/FFI; batch–incremental và state toàn danh mục ở P1.6/P1.7.
P1.5–P1.7, toàn G1, bindings và benchmark chưa được nghiệm thu.
