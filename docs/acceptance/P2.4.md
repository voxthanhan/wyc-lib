# Nghiệm thu P2.4 — parity Rust / Node.js / Python

Ngày 14/11/2026. **Đang kiểm chứng CI**, chưa tuyên bố đạt P2.4/G2.
Phạm vi đúng P2.4 trong IMPLEMENTATION_PLAN; áp dụng ủy quyền Git/CI tại
[AGENTS.md mục 12](../../AGENTS.md), không publish package/release/tag.

## Thay đổi

- `p2_parity_reference` gọi trực tiếp public `wyc_lib`/AnalysisState, không gọi
  shared transport; hai drivers chỉ gọi typed API từ npm/wheel đã cài ngoài source.
- Cùng actions/config qua 39 ca: arithmetic/temporal, 8 rolling, 6 basic,
  8 advanced, 15 structure. Batch và hai single-module entry points; replay
  update/batch, ba lựa chọn module/hai lịch availability cho structure,
  full snapshot tại as_of cũ, revision reset nửa lịch sử rồi append.
- Lỗi domain/new/reset/update, input giữ nguyên, records cũ qua update/reset,
  atomic failures/recovery; reconfigure/reset quá khứ và timestamp max-safe.
- Comparator kiểm exact shape/order/status/mask/ID/time/hash/error code/path;
  số thực theo tolerance P1, min/max và giá pivot/break exact. Năm negative
  controls kiểm comparator và matrix determinism. Không đổi Core/contract,
  thuật toán, runtime bindings, dependencies/lockfiles hoặc golden.

[Protocol](../../tests/parity/README.md) ghi lệnh chạy, scope và tolerance.
Reference Core chỉ là đối chiếu parity; oracle/golden độc lập P1 vẫn là gate riêng.
