## Phạm vi và hợp đồng

Chốt [ADR-0005](../adr/0005-p2-ffi-pilot.md): f64 hữu hạn, timestamp integer UTC ms
trong miền JS chính xác, tagged warm-up/missing/ready, config/result/schema,
exception có code/path, state handle owned/copy, close/GC và lỗi atomic.
Shared transport `bindings/ffi` chỉ decode/encode, phân loại lỗi và gọi public
Core; `bindings/node` dùng NAPI-RS, `bindings/python` dùng PyO3/Maturin.
API thử nghiệm: analyze_json và State với result/identity/update/reset/close.
Đầu vào/đầu ra là JSON string; chưa phải typed object hoặc NumPy adapter.

Không đổi thuật toán Core, fixtures/golden, schema `0.1.0`, engine `0.1.0`,
config-v1, event-v1 hoặc algorithm bundle `p1-v1`. Root workspace có năm package;
hai adapter native nằm trong workspace riêng với Cargo.lock riêng. Không
publish npm/PyPI, tạo release/tag hoặc công bố Foundation.
