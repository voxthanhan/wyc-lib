## Tiêu chí và sản phẩm

| Tiêu chí | Implementation/kiểm chứng |
| --- | --- |
| Swing High/Low | Strict L/R; đủ nến closed/available; observed_at tại pivot, known_at tại xác nhận/revision; plateau bị loại |
| Nhãn và trend | HH/HL/LH/LL/EH/EL; pivot đầu unclassified, unknown khi thiếu hai pivot mỗi loại; outside high trước low, tính trend một lần |
| BOS/CHoCH | Reference/trend trước nến hiện tại; close nghiêm ngặt; wick/equal không break; one-shot, unknown không tiêu thụ; CHoCH không tự đổi trend |
| Xung đột | Hai reference chưa tiêu thụ cùng kích hoạt trả invalid_result tại structure.breaks[i].references |
| Strength | abs(close-level)/(high-low), có thể >1; range=0 missing zero_denominator, overflow lỗi, underflow f64 |
| Evidence/ID | Pivot observation, break confirmation, confirmed theo rule; event-v1, toàn config hash; thứ tự/reference/time ổn định |
| Causal/revision | Mọi prefix của 15 fixture so full input và input cắt, thay future; append giữ lịch sử, delayed right/availability/open bar, revised snapshot |
| Biên/lỗi | Rỗng/ngắn/hằng, L/R=1/2/3/1000000, bất đối xứng, âm/zero/tiny/large; invalid config/data/gap; không sửa input |
| Ranh giới | market_structure → contracts, re-export qua wyc_lib; không chạy indicators, không state hoặc API điều phối giả |

## Giới hạn

Quét O(N×min(L+R+1,N)), sort evidence O(N log N), output/phụ trợ O(N),
validation O(M) gồm future. Overflow trung gian vẫn lỗi dù kết quả lý thuyết
hữu hạn, underflow theo f64. Chỉ một cấp structure, close break, không epsilon
hoặc wick-break. Không mutable state/batch–incremental, bindings hoặc benchmark;
P1.6/P1.7 và G1 chưa nghiệm thu. Không publish/tag hoặc đổi quyền repository.
