## Sản phẩm và kiểm chứng

[ADR-0009](../adr/0009-p2-ffi-baseline.md) chốt phương pháp;
[Foundation](../FOUNDATION.md) ghi cài đặt, compatibility, state và rollback.
Executable p2_baseline đo public Rust/shared transport release; workers Node/
Python chạy từ package đã cài ngoài source. Đo copy proxy, host snapshot/encode,
output decode, raw native transport, typed/typed-array/NumPy, Pandas/Polars và
batch so hai single-module calls trên cùng snapshot. Không thêm public API,
dependency, thuật toán, async/GIL release, unsafe hoặc zero-copy.

Ba input 64/256/1024 nến triangle-v1, 2 warmups, 5 samples, 3 iterations:
**66 rows, 330 samples/OS** (Rust 18, Node 21, Python 27 rows). Full outputs so
với direct Rust bằng comparator P2.4; single-module metadata/output đối chiếu
đúng wrapper. Input gốc và typed arrays giữ nguyên sau timing. Mỗi báo cáo lưu
min/median/max, throughput, input hash, binary/runtime/toolchain và CPU/wall/RSS.
Chín controls PASS Linux; Windows tám PASS và skip đúng regression Linux symlink.

Mỗi OS đạt **61 commands/native job**, --locked/checkout sạch trước-sau, 102
Rust tests, oracle/golden, Clippy/format/build, TypeScript/mypy strict và
4.409 parity actions/runtime, 39 fixtures, 2.514 equivalences, 57 lỗi/17 codes.
Node typed 83 assertions, Python plain 72/extras 79, host conversion 67;
JSON pilot 40 actions/runtime. Cài sạch/audit npm/wheel, Node/Python examples
và sáu ca HTTP trên mỗi Node/Next.js production server đều PASS.

source `36978aa`, main `4619e4d`, thay thế các số CPU/RSS Python cũ.
