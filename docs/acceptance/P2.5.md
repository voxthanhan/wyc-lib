# Nghiệm thu P2.5 — artifact, consumer và server

Ngày triển khai 16/11/2026. **Đang kiểm chứng**, chưa kết luận CI hoặc nghiệm thu.
Phạm vi theo IMPLEMENTATION_PLAN P2.5 và ủy quyền Git/CI tại AGENTS.md mục 12.

## Thay đổi

- Audit npm/wheel allowlist, metadata/target, PE/ELF x64, wheel CRC/RECORD;
  npm stage có os/cpu guard; manifest commit/SHA-256/size/target.
- Cài tarball offline không script và wheel không index/dependencies vào consumer
  mới ngoài source/venv; kiểm vị trí module thực nạp.
- Examples Node/Python gọi batch/single-module/state; HTTP Node và Next.js
  production build/start, mỗi server sáu ca success/error/recovery so Core.
- Next 16.4.6, React/React DOM 19.3.1 exact/lockfile; Node server runtime và
  external native package. Giữ toàn bộ parity/Core/host/type gates P2.4.

[ADR-0008](../adr/0008-p2-package-consumers.md) và
[ví dụ](../../examples/p2/README.md) ghi contract, lệnh chạy và giới hạn.
Không thay Core/API bindings/schema/config/hash/golden/Cargo locks.

Kết quả local, CI đúng SHA, source comparison, artifacts và tích hợp main sẽ
được ghi sau khi các lần chạy thực tế hoàn tất. Checkout D:/Dev/Lib có .git cũ;
bản sao source ở vùng làm việc khớp toàn bộ source/docs của main `9596c9c` trước
khi sửa. Không gọi bản sao này là checkout sạch hoặc coi CI cũ là CI P2.5.

## Giới hạn nghiệm thu

Chỉ Windows x64 MSVC/Ubuntu 24.04 GNU x64, Node 22.22.0, CPython 3.10.9;
Next/React đúng phiên bản trên. Chưa xác minh macOS/ARM/musl/manylinux/abi3,
Node/Python khác, Vercel/serverless/standalone, leak/RSS hoặc tải đồng thời.
Package chưa publish. P2.6 FFI baseline, G2 và Foundation còn mở.
