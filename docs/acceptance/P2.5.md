## Thay đổi và tiêu chí đạt

| Tiêu chí P2.5 | Bằng chứng thực chạy trên mỗi OS |
| --- | --- |
| Build npm/wheel đúng target | npm gồm đúng năm tệp, os/cpu/engine guards, header PE/ELF x64; wheel đúng cp310/platform, CRC và mọi digest/size RECORD |
| Cài artifact ngoài source | Consumer/venv mới, tarball offline không script, wheel no-index/no-deps; import location nằm trong node_modules/venv; consumer không có Rust source |
| Examples từ package đã cài | Node và Python gọi batch, hai single-module API và AnalysisState; so đầy đủ output với direct Rust reference; Python chạy `-I` trước khi cài extras |
| Node.js HTTP production | Sáu ca: batch, invalid shape, malformed JSON, missing data, negative volume, recovery; kiểm status và toàn bộ report/code/path |
| Next.js server production | `next build --webpack` rồi `next start`; cùng sáu ca HTTP; Node runtime và serverExternalPackages; Next 16.4.6, React/React DOM 19.3.1 exact/lockfile |
| Regression và nguồn | 56 commands/native job exit 0, locked/checkout sạch trước-sau; 113 source/build/test/package blobs khớp; 62 tệp Core/bindings/locks/fixtures/golden giữ nguyên |

Năm controls kiểm archive hợp lệ và từ chối tệp thừa/traversal, sai target,
sai binary, RECORD bị sửa. Không đổi thuật toán, runtime bindings, API,
schema/config/hash, ba Cargo.lock hoặc golden.

## Ma trận và giới hạn

Windows x64 MSVC (`windows-latest`) và Ubuntu 24.04 GNU x64; Rust 1.85.1,
Node 22.22.0, CPython 3.10.9, NAPI-RS 2.16.17/PyO3 0.23.5/Maturin 1.8.3.
Next/React đúng phiên bản ở trên. Npm là build riêng từng OS; wheel Linux
native tag, không phải manylinux/abi3. Không suy thành hỗ trợ macOS/ARM/musl,
Node/Python khác, Vercel/serverless/standalone hoặc container portability.

Smoke self-hosted production dùng dữ liệu synthetic và loopback; không phải
ứng dụng thị trường có auth, kiểm tải/concurrency hoặc chứng minh leak-free.
Lời gọi vẫn đồng bộ, owned-copy; baseline FFI/chuyển đổi/copy/batch thuộc P2.6.
Các tiêu chí G2 đã có bằng chứng P2.1–P2.5 không thay thế baseline và ứng viên
Foundation còn thiếu. Không publish npm/PyPI, tạo release/tag hoặc triển khai P3.
